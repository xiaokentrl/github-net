## 豁免清单（按钮文案随状态变化的例外）

按「文案固定不随状态变形」纪律，以下属于已登记的例外，不是偏差：

- **进度型**：单条 IP 重新检测的行内「重测中 N/M」、检查更新的「正在检查…」、同步状态的「同步中…」——它们表达「进行中」的事实本身，变形是反馈而非状态机漂移。
- **不可用置灰一律显原因**：所有置灰按钮必须有 title 说明（busy 原因、读取中、无可用 IP 等），本表各行已注明；哪颗按钮缺原因就是缺陷。

## 已知偏差（核实过、有意保留）

- 详情页各入口只看自己那项的 busy，工具栏四颗看全局 actionsBusy——两套口径并存。功能安全（队列串行＋同项去重＋后端互斥兜底），详情页可以发起工具栏此刻被拦的操作；保留是为了让详情页操作不被全队列拖住。
- 批量检测逐分组失败时原位错误只留最后一条（右下角每条都在）：多分组失败同现属罕见，原位聚合留待有真实需求再做。
