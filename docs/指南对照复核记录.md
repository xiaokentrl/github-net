## 缓建与待办（触发条件见括号）

- **事件载荷 TS 镜像无自动门**（task:progress/detect:progress 手写镜像）——需要把 payload 定义抽成单一来源生成两端；等下次动事件形状时一并做。
- **端到端升级实测**（真机从旧版经应用内更新升到新版＋失败注入）——需要「上一版已广泛安装」这个前提；v0.1.13 发布后下一版前做一次。
- **下载更新进度数字与磁盘不足分类**——小功能，等动更新体验时一起做。
- **SBOM/govulncheck 进 CI**——CI 侧加即生效，等流水线下一轮维护时补。
- **CSP 在目标 WebView 的实测记录、安装态冒烟**——需要真窗口操作，排进下次真机验收。
- **前端日志接线后端落盘、`lib/timing.ts` 收敛 setTimeout、DetectEmitter 合并 debug 痕迹、假时钟驱动延迟测试、延迟判定登记表**——防抖/日志二三四档项，统一排进对应专项。
- **启动四里程碑打点＋预算 CI 回归、`--data-dir` 绕过单实例**——单实例方案四档项。
- **配置 `$schema`/JSON Schema 生成/「打开配置」入口/未知键警告**——配置方案三四档项。
- **低盘保护、WebView 数据目录显式私有**——当前风险被 3 天保留期/默认位置缓释。
- **go-release（gorelease）门**——本项目是被引用性弱的桌面应用，明确暂缓。
