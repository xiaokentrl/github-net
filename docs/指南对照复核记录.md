### 实测暴露的两个真实缺陷（已修）

1. **纯标签推送触发打包重装**：重打标签的两次 push 把工作树（已升 0.1.14）打包装上本机，悄悄毁掉「旧版本在跑」的测试前提——钩子 stdin 全是 refs/tags/ 时直接放行（.githooks/pre-push）。
2. **release 标签核对步在 safe.directory 放行前跑 git 命令**，exit 128 红了一轮 Release（补放行；教训同 bindings 对账门——容器里 git 必须先放行）。

### 沉淀

- **弱网断点续传是真实需求**：应用内下载无断点续传，9MB 包在弱网两次失败；curl -C - 一次过。下载体验（进度/续传）从「三四档」升为「值得尽快做」。
- 升级链的其余环节（真实元数据、真实下载字节、真实验签、真实安装交接、真实升级结果）全部真机验证过。

## 下载进度与断点续传落地（2026-11-14，升级实测升级的那条）
