# 弹窗按钮文案：通用规划方案

## 这份方案是做什么的

弹窗按钮是用户做决策的最后一道关口——按钮文案写得含糊，用户就会点错。本方案把一条核心原则落为**可验收的文案规范**：

> **按钮写结果**——按钮文案直接描述点击后的结果或动作，禁止只写泛化的"确定/取消"。

**自查标准**：遮住标题只看按钮——若看不出点击后会怎样，就改按钮文案。

**与相邻方案的分工**：弹窗何时弹出 →《操作反馈方案》层级路由；Modal / MessageBox 组件本身 →《多平台一致组件库方案》；按钮多语言 →《多语言实现方案》；破坏性操作的 undo 策略 →《操作反馈方案》可反悔列。本方案只管**弹窗内按钮与标题的文案规则**。

## 核心规则

### 1. 按钮写结果，不写态度

| ❌ 泛化 | ✅ 写结果 |
|---|---|
| 确定 | 取消订单 |
| 取消 | 保留订单 |
| OK | 确认支付 ¥36.80 |
| 是 / 否 | 删除并退出 / 仅退出登录 |

**判定**：遮住标题只看按钮——若看不出点击后会怎样，就改文案。

### 2. 两个按钮不都叫"取消"

弹窗里"取消订单"和"取消"同时出现时，用户不知道哪个"取消"是哪个意思。正确做法：

- 确认按钮：写**具体动作**（"取消订单"）
- 另一个按钮：写**选择后的结果**（"保留订单"）
- 两个按钮都不叫"取消"——"取消"只用于关闭弹窗本身（即"放弃选择"）

### 3. 标题必须说明是哪件事

| ❌ 含糊标题 | ✅ 具体标题 |
|---|---|
| 提示 | 取消这笔订单？ |
| 确认操作 | 删除 3 个文件？ |
| 警告 | 退出前未保存的更改将丢失 |

标题回答"发生了什么 / 要做什么"，正文补充**后果说明**（如"取消后 36.80 元将原路退回"）。

### 4. "确定"仅用于纯告知

当弹窗**不需要用户做选择**（纯告知、无第二个动作）时，"知道了"是合法的——因为用户只有一个选项。一旦存在选择（确认 / 取消 / 忽略），"确定"就变成了含糊按钮。

## 弹窗类型 → 文案规则速查

| 类型 | 标题 | 确认按钮 | 另一按钮 | 示例 |
|---|---|---|---|---|
| 纯告知 | 说出事件 | 知道了 | （无） | "付款失败"→"知道了" |
| 确认 | 描述动作 | 具体动作 | 具体结果 | "取消订单" / "取消并退款" / "保留订单" |
| 危险确认 | 描述后果 | 具体危险动作 | 安全动作 | "永久删除 3 个文件" / "取消" |
| 输入 | 描述要填什么 | 具体提交动作 | 取消 | "新建文件夹" / "取消" |
| 选择 | 描述要选什么 | 具体选择 A | 具体选择 B | "使用模板" / "从空白开始" |

## 常见根因

| 表面现象 | 常见根因 | 预防 |
|---|---|---|
| 用户点错按钮 | 按钮文案泛化、不看标题 | 按钮写结果 + 遮标题自查 |
| 两个按钮都是"取消" | 一个"取消订单"、一个"取消"弹窗 | 另一按钮写选择后的结果 |
| 弹窗不知道在说什么 | 标题不含动作信息 | 标题说明是哪件事 + 后果说明 |
| 纯告知弹窗仍有"取消" | 习惯性加取消按钮 | 无选择 = 无取消 |
| 按钮在中英文间含义跳变 | 文案硬编码不走语言包 | 按钮文案全键化 |

## 测试矩阵

| 维度 | 覆盖 |
|---|---|
| 遮标题自查 | 每个弹窗只看按钮能否还原动作 |
| 双"取消" | 全应用搜索标题和按钮中同时出现"取消"的弹窗 |
| 纯告知 | 纯告知弹窗不含取消按钮 |
| 多语言 | 按钮文案在目标语言下不截断、不换行 |
| 后果说明 | 危险操作的弹窗含后果描述 |

## 给 AI 的实施约束模板

> 实现任何弹窗或确认框时，必须遵循"按钮写结果"原则：按钮文案直接描述点击后的结果或动作，禁止只写泛化的"确定/取消"；确认按钮写具体动作（如"取消订单"），另一个按钮也写清楚结果（如"保留订单"），避免两个按钮都叫"取消"造成歧义；标题必须说明是哪件事，必要时在下方补充后果说明（如"取消这笔订单？取消后 36.80 元将原路退回"）；"确定"仅可用于纯告知、无需用户做选择的场景（如付款失败后的"知道了"）；对于常做且可撤销的小事不要弹窗打扰。全部弹窗按钮文案走语言包键化。实现后用"遮住标题只看按钮，若看不出点击后会怎样，就改按钮文案"作为自查标准，逐弹窗验收。

方案确认后再改代码；按钮文案的最终措辞属产品决策，AI 给规则与推演，最终由用户裁决。

## 五档定位

- **一档**：文案规则写进组件库设计规范，作为 MessageBox / Modal / Banner 组件的按钮 props 约束。
- **二档**：全库弹窗按钮文案键化（→ 多语言实现方案）；遮标题自查通过。
- **持续**：新增弹窗时按本规则自查；多语言时按钮文案不截断、不换行。
