# 桌面应用立项专题指南库

跨项目复用的立项前规划指南集合。新项目立项时，**把整个 `guides/` 目录复制过去**，按主大纲走流程，深水区查对应专题。

## 指南清单

| 指南 | 定位 | 什么时候读 |
|---|---|---|
| [Wails3桌面项目立项总大纲](./Wails3桌面项目立项总大纲.md) | 主文档：五档节奏（编码前 / 可分发里程碑 / MVP / 公开发布 / 明确暂缓）的全部规划项 | 立项第一步，从这里开始逐档回答 |

| [托盘技术方案](./托盘技术方案.md) | 托盘、应用图标与桌面身份：身份映射、图标资源链路、统一唤回、降级路径 | 涉及托盘/图标/窗口身份/后台驻留的功能时 |

## 使用规则

1. **整体复制迁移**：新项目把 `guides/` 整个目录带走，指南之间的《书名号》引用在同目录下永远有效。
2. **主大纲是入口**：按五档节奏逐档回答「核心问题」、留出「验收证据」；条目标「→ 见专题指南」的，以专题指南为准。
3. **专题指南是深水区**：主大纲只列准入问题；每个专题的全部检查清单、根因表和验收矩阵在专题指南里。

## 新增专题指南的约定

- 文件名 = 主题名，放本目录；涉及具体框架的深坑写进对应专题，通用原则写进主大纲。
- 结构遵循既有三段式：**核心问题 → 验收证据**；需要分档的沿五档节奏。
- 收录新指南时同步更新本清单；删条目或改语义时检查其他指南的《书名号》引用。
- 项目实战教训（哪个项目踩了什么坑）不写进指南正文——指南保持通用，教训进各项目自己的文档。
