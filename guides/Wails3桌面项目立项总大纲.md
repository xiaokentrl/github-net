# Wails3 + Go 桌面应用立项总大纲（五档节奏）

## 〇、如何使用这份大纲

五档是时间轴，不是重要级排序：

| 档位 | 定义 | 准入/准出规则 |
|---|---|---|
| 一档 | **不回答就不应开始编码** | 任意一项没有答案 → 不写业务代码 |
| 二档 | 第一个可分发里程碑前锁定 | 任意一项没有答案 → 不声称「可分发基线已建立」 |
| 三档 | MVP 阶段应当就位 | 缺项可以带债进 MVP，但每笔债要登记 |
| 四档 | 首个公开发布前补齐 | 缺项不得发布 |
| 五档 | 可以明确暂缓 | 每笔暂缓必须有**书面理由 + 触发重新评估的条件**——裁剪是被记录的决策，不是被遗忘的遗漏 |

每项按两段填写：**核心问题 → 验收证据**。

## 版本与平台基线声明（2026-11）

- 平台：Windows / macOS / Linux 桌面三平台；iOS 与 Android 不支持。
- **Linux 最低版本：Ubuntu 26.04**（含之后所有版本）。更早的 Ubuntu 和其他发行版一律不在支持范围内，不做多发行版兼容矩阵。
- 该基线下 Linux 自带 GTK4 + WebKitGTK 6.0，直接用框架默认栈，不需要任何兼容分支。
