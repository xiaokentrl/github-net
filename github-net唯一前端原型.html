网络与流量

按当前网络情况选择检测范围。档位立即保存并用于之后启动的检测；正在运行的任务继续使用启动时的设置。

⌁检测档位

降低并发主要减少同时占用；减少每域名候选数和每轮上限，才能直接减少尝试次数。

⇣每轮候选 IP 上限

限制本轮所有待检测项目合计尝试的候选数；达到上限后，剩余项目会标记为未检测，不会悄悄跳过。

个候选 IP 设置已保存
当前原型用每个菜单项目模拟候选列表，不会发起 DNS/TLS 请求；并发数仅为模拟任务的并发上限。真实应用将按域名解析候选，并由后端统一限制并发和请求量。后台自动检测默认关闭，流量字节数无法精确等同于运营商计费量。

检测与应用

控制执行检测或应用时，主菜单是否自动展开当前项所在类目。

◎检测时焦点跟随

开启后，点击「检测全部」时会自动收起其他类目，只展开当前正在检测的项所在类目； 检测完成后恢复检测前的折叠状态。 关闭时保持用户当前的折叠状态不变，仅通过金色高亮提示当前检测项。

◎应用时焦点跟随

开启后，点击「应用队列」时会自动收起其他类目，只展开当前正在应用的项所在类目； 应用完成后恢复应用前的折叠状态。 关闭时保持用户当前的折叠状态不变，仅通过蓝色高亮提示当前应用项。

界面缩放

⤢缩放比例

◐语言

托盘

系统托盘区的显示与窗口关闭行为。

▣关闭窗口时最小化到托盘

点击窗口关闭按钮时隐藏到系统托盘，不退出程序。只有通过托盘菜单「退出」才真正退出。

▤显示托盘图标

在系统托盘区显示图标，右键可快速访问常用操作。

开机自启动

系统登录后自动拉起后台 daemon，让 GitHub 加速始终生效。

▶登录时自动启动

在用户登录后通过计划任务（Windows）、LaunchAgent（macOS）或 systemd（Linux）自动启动后台服务。

▾启动后最小化

自启动时隐藏主窗口，只在托盘显示，避免每次登录都弹窗。

◎自动检测已选

应用启动后，自动对所有已勾选的项执行一次检测。 没有勾选项时跳过本次自动化。 检测过程中的焦点跟随由「检测时焦点跟随」开关决定。

◎自动应用队列

检测完成后，自动把检测成功的项加入应用队列并执行。 依赖「自动检测已选」，未开启检测时此项不可用。 检测失败或没有可用 IP 的项会自动跳过。
